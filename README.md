# godbolt-C--polymorphic-function-templates-for-C-11
Godbolt C++ polymorphic function templates for C++/11 using type_traits et al to ensure the compiler picks the desired incantation for each function argument type. Restricted to C++/11, not because I don't like C++/20 and onwards, but because my embedded dev env (Arduino Due) is forever stuck at that version (yech!)
